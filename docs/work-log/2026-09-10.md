## 四、踩坑教训（已同步到项目记忆）

1. **子组件不能引用父组件作用域变量**（ref：feat/140）：子组件（订单详情弹窗）的删除按钮显示条件用了主组件的 `isBookingOperator`，子组件访问不到导致 ReferenceError 崩溃。必须用子组件已有的 prop（`canOperate`），不能跨作用域引用。
2. **git amend 必须确认当前分支**（ref：feat/140）：amend 时误在 main 分支执行，commit 落到了 main。必须 amend 前先 `git branch --show-current` 确认分支，误操作后 `git reset --hard <原main指针>` 剥离。
3. **付款方式配置化需同步缓存升版**（ref：feat/141）：BizConfigModal 的 localStorage 缓存 key 必须从 v1 升到 v2，否则旧缓存无 paymentMethods 字段导致下拉为空。新增配置 Tab 时缓存 key 必须升版。
4. **康乐改价用 customAmount ?? 自动价 优先链**（ref：feat/142）：所有金额计算逻辑（4 处 reduce）都必须加 `x.customAmount ?? calcWellnessAmount(...)`，漏一处会导致合计与实际不符。
5. **体检备注合并时需双向兼容**（ref：feat/142）：合并 placeholderNote 到 remark 后，编辑恢复必须优先读 remark 兼容旧 placeholderNote；保存时占位模式同时写两个字段，确保旧版本前端也能读到。
