## 二、feat/178：出入库记录支持按物资名称搜索

### 2.1 背景

出入库流水记录默认按时间倒序分页，用户需要按物资名称搜索定位某物资的出入库历史。

### 2.2 改动（2 files，+15/-2）

**后端** [stock-movements.js](file:///f:/OA/backend/routes/stock-movements.js)
- `GET /` 解构新增 `item_name` 查询参数
- **主查询**加 `if (item_name) { sql += ' AND sm.item_name LIKE ?'; params.push(\`%${item_name}%\`); }`（L67）
- **count 查询**同步加同样的 LIKE 条件（L86）
- 两条查询条件必须一一对应，否则分页总数错误

**前端** [StockMovement/index.tsx](file:///f:/OA/src/pages/StockMovement/index.tsx)
- 新增 `itemName` state
- `fetchMovements` 传递 `item_name: itemName.trim() || undefined`
- `useEffect` 依赖数组追加 `itemName`，实现输入即查
- 筛选栏新增物资名称文本输入框，位于类型下拉和日期范围之间

### 2.3 提交

`7cbd1d9` → merge `4bd9df7`

### 2.4 关键决策

- **用 `sm.item_name` 而非 JOIN items 表**：流水表已有冗余的 `item_name` 字段，LIKE 匹配直接用，无需 JOIN，性能更好
- **LIKE '%关键词%'**：前后模糊匹配，支持物资名称中包含关键词的所有记录
- **输入即查**：useEffect 依赖 itemName，无需点搜索按钮
