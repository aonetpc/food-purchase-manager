## 二、订单详情住宿数量列修复（fix/098-lodging-quantity-col）

### 2.1 问题

用户截图反馈：订单详情弹窗未展开行的数量列，住宿按人计费时显示 **40 间**（错误），展开后显示 **20 间**（正确）。

### 2.2 根因

```tsx
// L1259-L1272 原代码：住宿走到最终 else 分支
return <>{it.pax}{biz.unit}</>;  // it.pax=40(人夜), biz.unit='间' 硬写死 → 40间
```

- `it.pax` 在按人计费模式下存的是**人夜总数**（20人 × 2晚 = 40人夜）

- `biz.unit` 对 lodging 永远写死 `'间'`

- 两者拼接 → 错误显示 40 间

### 2.3 修复

在 `lunch/dinner` 三目与最终 `else` 之间插入 `it.itemType === 'lodging'` 专属分支：

```tsx
it.itemType === 'lodging' ? (() => {
  const ex = it.extra as any;
  const pm = ex.pricingMode || 'per_room';
  const beds = Number(ex.bedsPerRoomSnapshot) || getBedsPerRoom(ex.lodgingType || 'standard', bizCfg as any) || 2;
  let rooms = Number(ex.rooms);
  if (!(rooms > 0)) {
    if (pm === 'per_room') rooms = Number(it.pax) || 1;
    else rooms = Math.max(1, Math.ceil(paxBase / beds));  // 按人模式：ceil(人数/床数)
  }
  return `${rooms}间`;
})()
```

**Commit**: `a0310b4` — fix(098): 订单详情弹窗住宿数量列 — 按人计费红框40间→20间

### 2.4 关键约束

- 仅改红框位置（详情弹窗未展开数量列），不动展开区/不动甘特卡片/不动 cardSummary

- rooms 兜底优先级：`ex.rooms` → `per_room` 用 `it.pax` → `per_person` 用 `ceil(pax/beds)`

- 老订单（无 ex.rooms/ex.pax）兜底按 beds 反推，不显示 0 间

  // ... 代码
  let reviewWarn = null;  // ← 声明在 try 块内部
