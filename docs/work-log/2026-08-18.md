### 4. 修复编辑单人项目弹窗崩溃 ReferenceError（P0）

- **问题**：点体检名单里的「✎ 编辑」按钮后，单人弹窗直接白屏，控制台报 `ReferenceError: pax is not defined`。
- **根因**：上一步改造 `CapsuleItemPicker` 时，把 `PaxItemsEditor` 组件的 props 解构从 13 个变量简化到只剩 3 个（`checkupItemsLib, items, fallbackLib`），但下方 JSX 仍然直接引用其余 10 个**未定义的裸变量名**（`pax / paxAmount / hasCustom / pkgName / pkgCode / index / onRemoveItem / onUpdateItemField / onReset / onAddItem`），运行时直接 ReferenceError 崩溃。
- **修复方案**：
  ```tsx

  // 修改后（13 个全部补齐）
  const {
    index, pax, paxAmount, items, hasCustom, pkgName, pkgCode,
    checkupItemsLib, onRemoveItem, onUpdateItemField, onReset, onAddItem,
    fallbackLib = [],
  } = props;
  ```
  同时把 confirm 函数里 `props.onAddItem(ci)` 统一为解构的 `onAddItem(ci)`；`PackageGroupSummary` 解构补上漏掉的 `pkgPrice`。

### 🟡 出错2：胶囊面板层级/裁剪问题

📌 **错误过程**：
1. 新增 `CapsuleItemPicker` 时，弹出面板用了 `absolute` 定位 + `z-20` 遮罩
2. 但面板被调用在 modal（`z-[80]` + `overflow-y-auto`）内部
3. `absolute` 在 `overflow-y-auto` 容器内 → 面板被裁剪
4. `z-20` < `z-80` → 遮罩被 modal 盖住，外部点击关不掉

📌 **教训 & 规则**（弹层嵌套定位策略）：
1. **弹层嵌套时，内层弹层必须用 `fixed` 而非 `absolute`**：`fixed` 相对视口定位，不受父级 `overflow` 裁剪
2. **内层 z-index 必须高于外层**：modal 是 `z-[80]` → 内层遮罩至少 `z-[95]`、面板 `z-[96]`
3. **用 `useLayoutEffect` + `getBoundingClientRect()` 计算锚点视口坐标**：`absolute` 用 `top-full left-0` 就行，`fixed` 需要手动算坐标
4. **智能方向判断**：按钮下方空间不够时自动翻到上方（`placeUp` 用 `bottom` 代替 `top`）
5. **滚动/缩放时实时重算位置**：监听 `scroll` / `resize` 事件

### 🟡 出错3：GitHub Token 过期 + scope 不足

📌 **错误过程**：
1. 旧 token `[REDACTED]...` 失效 → push 报 `Password authentication is not supported`
2. 用户生成新 token `[REDACTED]...` → 但没勾 `repo` scope → push 403
3. 用户重新生成 `[REDACTED]...` 勾了 `repo` → push 成功

📌 **教训 & 规则**（GitHub Token 管理规范）：
1. **Classic PAT 必须勾选 `repo` scope**（顶层大复选框）才能推送私有仓库
2. **token 不要硬编码在脚本/remote URL 里**：push 成功后立即 `git remote set-url origin "https://github.com/user/repo.git"` 清掉 token
3. **token 过期时间建议 30-90 天**，不要永不过期
4. **生成 token 时 Note 必填**（GitHub 强制要求，方便将来管理/吊销）
5. **不要在对话/日志中明文留 token**：本次日志中已脱敏处理
6. **失效的旧 token 立即在 GitHub 删除**：避免 token 名额浪费和安全隐患

### ⚠️ 注意2：身份证号解析的容错性

`parseIdCardMeta()` 函数从身份证 18 位提取性别和出生日期，需要注意：
1. **只支持 18 位身份证**：15 位老版身份证不支持（现在基本见不到了）
2. **第 17 位奇数=男，偶数=女**：这是国家标准，不会变
3. **身份证号校验位不验证**：只提取不校验合法性（避免误判合法用户输入）
4. **粘贴时列顺序自适应**：但如果用户粘贴的列顺序不是 `姓名,身份证,手机,性别` 可能解析错位
5. **性别已手动指定时不覆盖**：只有性别为空/默认值时才从身份证推断

以后遇到 `sudo bash xxx-deploy.sh` 类操作时，**必须先做以下检查**：

| # | 检查项 | 命令/方法 |
|---|--------|-----------|
| 1 | 下载脚本看正文 | `wget -O /tmp/deploy.sh <URL>` + `cat /tmp/deploy.sh` |
| 2 | 搜索危险关键词 | `grep -nE 'nginx restart|ufw|firewall|pm2 (delete\|stop\|restart) all|chown -R /|rm -rf' /tmp/deploy.sh` |
| 3 | 检查 Nginx default 删除 | `grep -n 'rm.*default' /tmp/deploy.sh` → 如果有，先确认 OA 站不在 default 里 |

| 5 | 备份再执行 | `sudo cp -a /etc/nginx /etc/nginx.bak.$(date +%Y%m%d-%H%M)` |
| 6 | 首选手动分步 | 一键脚本适合「验证过的重复部署」，第一次部署必须手动 |
